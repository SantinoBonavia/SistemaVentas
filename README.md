# Sistema de Ventas

Proyecto desarrollado en Java con MySQL.

## Objetivo

Crear un sistema de ventas que permita gestionar:

- Clientes
- Categorías
- Productos
- Stock
- Ventas
- Detalle de ventas

## Tecnologías

- Java
- MySQL
- JDBC
- IntelliJ IDEA
- MySQL Workbench
- PlantUML

## Documentación

Los diagramas UML se encuentran en:

`docs/uml/`

## Estado del proyecto

Actualmente se encuentra en etapa de diseño y modelado de la base de datos.
